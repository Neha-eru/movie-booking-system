# Movie Booking Backend (minimal)

This is a minimal Spring Boot backend skeleton for a movie booking app.

Build & run (from backend folder):

```powershell
mvn clean package -DskipTests
mvn spring-boot:run
# or
java -jar target/movie-booking-backend-0.0.1-SNAPSHOT.jar
```

Open https://movie-booking-system-ja3o.onrender.com/movies to see seeded movies. H2 console available at /h2-console (jdbc:h2:mem:testdb).
